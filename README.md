# 潮粮折干结算器

给粮站结算员用的单页小工具：按当天挂牌价，把潮粮折成干粮再算钱。
纯前端、零依赖、数据只存在本机浏览器，不需要联网和服务器。

## 打开方式

直接双击 `index.html` 用 Chrome/Edge 打开即可；或在本目录运行：

```bash
npm start        # 等价于 python3 -m http.server 8000，访问 http://localhost:8000
```

跑测试：

```bash
npm test
```

## 操作流程

1. **挂牌价**页签：登记当天单价（元/吨或元/斤，右上角切换，自动 ×2000 互转）。
2. **结算**页签 →“新车过磅”：填车牌、司机；每过一趟磅录一行（毛重、皮重、
   化验室水分、容重、杂质、化验单号）。一车两趟就点“再加一趟”。
3. 化验室水分与磅房复检水分对不上时，两个数并排显示，单子挂起，由人工点选采用哪个。
4. 看底部折干结算重量与金额，点“开具结算单”即打印；水分超标自动变“开具拒收单”。
5. **单据**页签可补打；要改账只能“重算（另开新单）”，原单不动，新单上写原单号。

## 折干口径（默认玉米标准，可在“标准设置”改）

- 净重 = 毛重 − 皮重。
- 水分三段：≤14% 安全段不扣；14%~20% 中间段，扣率 = (水分−14) × 水分扣量系数(默认每点1%)；
  ≥20% 超标，该车出拒收单、金额 0。
- 容重按等级扣率：一等 ≥690 不扣、二等 ≥660 扣1%、三等 ≥630 扣2%、等外扣4%（可改）。
- 杂质扣率 = (杂质−基准1%) × 杂质系数(默认每点1%)，下限 0。
- **结算重量 = 净重 ×(1−水扣)×(1−容重扣)×(1−杂质扣)**，三样乘法联动。
- 一车多趟：每趟按各自化验单折干后再相加；金额 = 合计折干吨数 × 当天挂牌价。
- 水分换算：湿基 → 干基 = M湿 ÷ (1 − M湿)，右上角“湿基/干基”只改显示报法，账永远按湿基原始数算。

## 十一条业务规则落在哪

| # | 规则 | 实现位置 |
|---|------|----------|
| 1 | 毛重减皮重，水分按化验单折 | `js/engine.js` `evaluateTrip` |
| 2 | 安全/中间乘系数/超标拒收三段 | `moistureClass`/`moistureRate`，拒收出拒收单 |
| 3 | 水分档×容重等级×杂质含率联动 | `evaluateTrip` 综合系数 |
| 4 | 两个水分并排等人点，不自己挑 | 未点定返回 `MOISTURE_PENDING`，禁止开单 |
| 5 | 只用当天挂牌价，过零点按次日价 | `settleDraft` 按 `settleDate/当天` 取价，跨日横幅 |
| 6 | 湿基改干基报并标化验单号 | `wetToDryBasis`，单据每行列化验单号+报法 |
| 7 | 元/斤↔元/吨全表切换，旧单不动 | 只改显示；单据冻结开单时单位并附另一单位 |
| 8 | 一车两趟净重合计、各按各化验单 | 多趟次逐趟折干后求和 |
| 9 | 系数改后只管之后过磅的车 | 每趟保存时冻结 `configSnapshot` |
| 10 | 已开单据不能改，重算另开新单写原号 | `issueBill` 只追加；`recalcOf` 记原单号 |
| 11 | 重算只能从第一趟重新走 | “另开新单”不带旧趟次，逐趟重录 |

## 文件结构

- `index.html`、`css/styles.css`：界面与打印样式（打印时只出单据）。
- `js/engine.js`：纯函数计算核心，浏览器和 Node 共用。
- `js/store.js`：localStorage 存取、单据编号、过磅系数快照。
- `js/app.js`：界面交互。
- `test/`：核心规则与工作流测试（`node --test`）。

## 备份

“数据”页签可导出/导入 JSON，换电脑或留档用；清除数据前请先导出。
