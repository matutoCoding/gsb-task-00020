# 潮粮折干结算器

给粮站结算员用的潮粮折干结算工具：登记毛重/皮重和化验单数据，按当天挂牌价把潮粮折成干粮算钱。
纯前端单页应用，双击 `index.html` 即可使用，数据保存在浏览器本地（无需联网、无需安装）。

## 运行

- 使用：直接用浏览器打开 `index.html`（Chrome / Edge）。首次打开自带演示数据，点右上角「恢复演示数据」可重置。
- 测试：`node --test`（需要 Node 18+），14 个用例覆盖下面 11 条业务规则。

## 文件

- `index.html` / `css/style.css` / `js/app.js` —— 界面（车辆结算、已开单据、挂牌价与规则三个页签）
- `js/domain.js` —— 扣量/折干/计价纯函数
- `js/store.js` —— 车辆、趟次、单据、牌价、系数版本、跨零点、开单/重开单
- `test/` —— Node 测试

## 结算口径

- 净重 = 毛重 − 皮重；重量保留到 0.5 kg（一市斤），金额保留到分。
- 水分三段：≤ 安全水分(默认14%)不扣；安全线～拒收线(默认30%)之间，每超 0.5 个点为一档，
  每档扣 1%，再乘当前水分扣量系数；超过拒收线整车该趟拒收，不计入结算。
- 杂质同理：超过安全杂质(默认1%)后每 0.5 点一档、每档 1%，乘杂质扣量系数。
- 容重按 g/L 自动落等（一等0%、二等1%、三等2%、等外4%，均可在规则页改；等级也可标记为拒收）。
- 三样扣率按 **水分 → 杂质 → 容重** 连乘，改其中一样，另两样的扣量随之变化。

## 十一条规则落点

1. **毛重减皮重**：每趟录入毛/皮，净重自动算，多趟净重合计。
2. **水分三段**：安全段不扣、中间段乘扣量系数、超标拒收（拒收趟单列、不计价）。
3. **三样联定**：水分档、容重等级、杂质含率连乘，联动重算。
4. **水分对不上**：化验室与磅房复检不一致时，两个数并排显示，由结算员点定「用化验室/用磅房」，
   未点定不能开单；系统不自动挑选。
5. **当天牌价**：未开单的车价格日期跟随当天；页面每秒校时，跨零点自动落到次日牌价重算并提示；
   已开单锁死在开单日。牌价缺失时不能开单。
6. **湿基/干基**：每车可选给司机报干基（折干重量×挂牌价）或湿基（同金额折成湿粮单价），
   两种口径金额相同；每趟及单据上均标注实际采用的化验单号。
7. **每吨/每斤**：顶栏切换后所有未开单行与列表同步换算（2000 元/吨 = 1 元/斤）；
   已开出的单子存快照，金额与显示单位均不变。
8. **一车多趟**：「+ 增加一趟过磅」，两次净重加总；每趟各挂各的化验单、各算各的水分扣量。
9. **系数改后生效**：扣量系数按生效时间版本化，每趟按其过磅时刻取当时系数，旧车不追溯。
10. **单子不可改**：开单后车辆与单据锁定；重算点「重开一张」，生成新单号并在新单上写明原单号，
    原单标记「已被新单取代」。
11. **重算从第一趟起**：重开向导必须从该车第一趟开始逐趟核对，趟数不齐直接拒绝，不能只改后面某趟。
